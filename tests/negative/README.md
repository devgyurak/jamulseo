# 실패 케이스 회귀 코퍼스

> 이 디렉터리는 **추가만** 가능하다. 수정·삭제는 사람만 한다 (`.agents/APPROVAL.md`).
> 퍼징·리뷰·버그에서 나온 재현 입력은 **즉시** 추가한다.

범주와 기대 동작: `docs/TESTING.md §5`.

각 항목은 다음을 담는다 (형식은 M3 에 러너와 함께 정한다):
- 호출할 함수와 인자 (길이, 포인터 관계 — 겹침은 오프셋으로 표현)
- 기대 오류 코드
- **무변경 확인 대상** (센티널로 채울 출력 버퍼, 컨텍스트 상태)
- 출처 (계획서 목록 / 퍼징 크래시 ID / 리뷰 [P1] / 이슈)
