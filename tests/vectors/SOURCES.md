# 정답 벡터 출처

> 벡터 데이터 파일은 **새 파일 추가만**, 이 파일은 **끝에 행 추가만** 가능하다 (scripts/hooks/protected.tsv).
> 기존 행을 고쳐야 하면 사람이 한다 — 출처가 바뀌면 벡터의 의미도 바뀐다.
> 기존 벡터 파일에 벡터를 더하고 싶으면 **새 파일**로 넣는다 (레코드 중간 삽입으로 기대값을 바꾸는 것을 막기 위해서다).

확보 예정 (계획서 §테스트·검증 전략): KISA 검증대상 알고리즘 테스트 벡터(ARIA·ARIA-GCM·SHA-256·HMAC, 사람이 확보),
RFC 5794 Appendix(ARIA), NIST CAVP SHAVS(SHA-256), RFC 4231(HMAC-SHA-256). RFC 원문은 `docs/standards/` 에 있다.
