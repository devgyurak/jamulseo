```
./scripts/repro.sh
```

## 무엇을 하는가

저장소를 두 개의 서로 다른 임시 경로로 복사해 같은 툴체인·`SOURCE_DATE_EPOCH`·`--remap-path-prefix` 로
릴리스 `cdylib` 을 빌드하고 SHA-256 을 비교한다. CI 는 **서로 다른 두 러너**에서 같은 일을 한다.

Linux x86_64 가 아니면 **실행 불가** — 검증 대상 바이너리는 ELF 다.

## 불일치가 나면

1. `diffoscope` 가 있으면 두 산출물을 비교해 차이 위치를 본다
2. 흔한 원인: 절대 경로(패닉 메시지·디버그 정보), 빌드 시각, `HashMap` 순회 순서에 의존한 코드 생성,
   `target-cpu=native`, 툴체인·링커 버전 차이, 환경 변수
3. 원인을 고친다. 비교 대상을 줄이거나(예: 섹션 제외) 해시 대신 크기를 비교하는 식으로 **느슨하게 하지 않는다**

## 이것이 보장하지 않는 것

재현 빌드는 "공개 소스와 고정 툴체인에서 공식 바이너리가 나왔다"를 제3자가 확인하게 할 뿐이다.
사용자가 직접 빌드한 결과물에 검증효력을 주지 않는다 (계획서 §빌드·배포·형상관리).
