```
./scripts/verify.sh $ARGUMENTS
```

| 시점 | 명령 |
|---|---|
| 개발 중·push | `./scripts/verify.sh --fast` |
| 머지 (CI) | `JMS_REQUIRE_ALL=1 ./scripts/verify.sh` — 뮤테이션은 diff 범위 |
| 마일스톤 종료 (기준 장비) | `JMS_REQUIRE_ALL=1 JMS_CT_BASELINE_HOST=1 ./scripts/verify.sh --milestone Mx` — 뮤테이션 전체, dudect 포함 |

기본 마일스톤은 `scripts/_common.sh` 의 `CURRENT_MILESTONE` 이다.

## 결과 읽는 법

| 상태 | 뜻 | 보고할 때 |
|---|---|---|
| 통과 | 실행했고 기준 만족 | "통과" |
| 실패 | 실행했고 미달, 또는 필수 도구·하네스·결과 부재 | 고친다 |
| 미적용 | 현재 마일스톤 이전에는 요구되지 않음 | **"통과"라고 쓰지 않는다** |
| 실행 불가 | Linux x86_64 가 아니라 판정 불가 (CT·ABI·ASan·재현 빌드) | **"통과"라고 쓰지 않는다.** CI 결과를 기다린다 |

macOS 에서 돌린 `--full` 은 머지 판정이 아니다. CI(`JMS_REQUIRE_ALL=1`)가 판정한다.

## 실패 시 대응

| 게이트 | 올바른 대응 | **하면 안 되는 것** |
|---|---|---|
| clippy | 코드를 고친다 | `#[allow(...)]` 추가 |
| GWT 네이밍 | 테스트 이름을 고친다 | 린트 제외 |
| 경계 규약 | 의존·속성을 고친다 | 린트 예외 추가 |
| 정답 벡터 | 구현을 고친다 | 벡터 수정·삭제 |
| 커버리지 | **테스트를 추가한다** | 임계값 낮추기, assert 없는 테스트 |
| 계약 역방향 | 누락 테스트를 쓴다 | 레지스트리 항목 삭제·마일스톤 미루기 |
| **뮤테이션** | **테스트를 강화한다.** 관측 불가능하면 사람에게 면제 요청 | 구현을 고치기, 억지 테스트 |
| 상수 시간 (11 ctgrind / 11b dudect) | 구현을 고치고 `/jms-ct --asm` 으로 확인 | 재실행해서 통과하길 기대, 임계 완화 |
| ABI | 의도한 변경이면 사람에게 승인 요청 | `exports.txt`·헤더를 맞춰 고치기 |
| 퍼징 | 재현 입력을 `tests/negative/` 에 고정하고 고친다 | 크래시 입력 버리기 |
| 재현 빌드 | 비결정 요소를 찾는다 | 해시 비교 완화 |

> **게이트를 통과시키기 위해 게이트를 고치는 것은 금지다 (R4, R5).**
> `scripts/**` 전체, `.githooks/`, `.github/`, 도구 훅 설정, 계약 레지스트리의 마일스톤·검사 종류는 판정기가 막는다. 셸로 우회하지 않는다.

## 게이트 통과 후

`/jms-review` 로 교차 리뷰를 진행한다. **구현한 세션이 자기 코드를 리뷰하지 않는다 (R3).**
