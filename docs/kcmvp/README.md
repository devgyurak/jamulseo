# KCMVP 제출물 초안

> **초안이다.** jamulsoe 는 KCMVP 검증을 **준비 중**이며, 검증서가 발급되지 않았다.
> 이 디렉터리의 어떤 문서도 "검증됨·인증됨"을 주장하지 않는다.

근거: `docs/PLAN.md §KCMVP 요건 매핑`. 검증 기준은 KS X ISO/IEC 19790(보안 요구사항)·24759(시험 요구사항),
해석은 GVI Part 1.

## 파일

| 파일 | 내용 | 누가 고치나 |
|---|---|---|
| `inquiries.md` | 시험기관·KISA·NSR 에 보낸 질문과 **받은 답변** | **사람만** |
| `inquiry-drafts.md` | 보낼 질문 초안 | 에이전트·사람 |
| (M5) 보안정책문서 초안 | 승인 알고리즘, 운영환경, 서비스·상태 표, CSP 인벤토리, 자가시험, 한계 | `kcmvp-writer` |
| (M5) 기본·상세 설계서 초안 | 크레이트 구조, 상태머신, 언어 특성(소유권·unsafe 경계) 설명 절 | `kcmvp-writer` |
| (M5) 형상관리문서 초안 | 툴체인 기준선, 서명 태그, 브랜치 정책, 개발 절차(교차 리뷰·승인 경계) | `kcmvp-writer` |
| (M5) 사용자 안내서 초안 | IV 구성 규칙(SP 800-38D 결정적 구성), 키당 최대 호출 횟수, 호출자 계약 | `kcmvp-writer` |

장 구성은 KISA 「암호모듈 제출물 작성 안내서(2025.9.)」를 확보한 뒤 그 목차에 맞춘다. 그 전에는 확정하지 않는다.
